下载VideoTranslator-macOS.zip
首次打开会被 macOS 拦截（最重要）
  因为这不是从 App Store 下载的，Mac 会提示 "无法打开，因为无法验证开发者"。
  解决方法：右键点击 App → 打开 → 弹窗里再点一次 "打开"。
  或者去 系统设置 → 隐私与安全性 → 下方找到拦截记录 → 点击 "仍要打开"。
首次运行必须联网（自动下载模型）
  第一次打开软件时，会自动下载：
  Whisper 语音识别模型（约 150MB）
  MarianMT 翻译模型（约 300MB）
  下载一次后永久缓存，以后断网也能用。如果网络不好，首次打开可能会卡一会儿，属于正常现象
